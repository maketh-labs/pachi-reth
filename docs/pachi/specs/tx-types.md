# Transaction Types Reference

## Summary

| Type ID | Name | Purpose | Signer | Gas Payer | msg.sender |
|---------|------|---------|--------|-----------|------------|
| `0x04` | SessionTx | Session key delegated execution | Session key | Authorizer | Authorizer |
| `0x05` | SponsoredTx | Gas fee sponsorship | Sender (EOA) | Sponsor | Sender |
| `0x06` | SessionSponsoredTx | Session key + Gas sponsor combined | Session key | Sponsor | Authorizer |
| `0x50` | PachiSystemTx | System operations (Oracle, VRF fulfill) | None (unsigned) | Free (prepaid or protocol) | System address |

---

## SessionTx (0x04)

```
SessionTx = 0x04 || rlp([
  chain_id,
  nonce,                        // session key nonce (NOT authorizer nonce)
  max_priority_fee_per_gas,
  max_fee_per_gas,
  gas_limit,
  to,
  value,
  data,
  access_list,

  // -- Session extension fields --
  session_hash,                 // bytes32
  authorizer,                   // address (main wallet)
  session_config,               // bytes: ABI-encoded SessionConfig (for hash verification)

  // -- Signature (by session key) --
  v, r, s
])
```

- **Gas payer:** authorizer (main wallet)
- **msg.sender:** authorizer
- **Additional calldata:** session_config size (300B - 4KB, MAX_POLICY_SIZE = 4KB)

---

## SponsoredTx (0x05)

```
SponsoredTx = 0x05 || rlp([
  chain_id,
  nonce,                        // sender's nonce
  max_priority_fee_per_gas,
  max_fee_per_gas,
  gas_limit,
  to,
  value,
  data,
  access_list,

  // -- Sponsor extension field --
  sponsor,                      // address (policy looked up from on-chain registry)

  // -- Signature (by sender) --
  v, r, s
])
```

- **Gas payer:** sponsor (Deposit: balance deduction / Mint: protocol minting)
- **msg.sender:** sender
- **Additional calldata:** +20 bytes (sponsor address only; policy is on-chain)

## SessionSponsoredTx (0x06)

```
SessionSponsoredTx = 0x06 || rlp([
  chain_id,
  nonce,                        // session key nonce
  max_priority_fee_per_gas,
  max_fee_per_gas,
  gas_limit,
  to,
  value,
  data,
  access_list,

  // -- Session fields --
  session_hash,                 // bytes32
  authorizer,                   // address
  session_config,               // bytes (for hash verification)

  // -- Sponsor field --
  sponsor,                      // address (registry lookup)

  // -- Signature (by session key) --
  v, r, s
])
```

- **Gas payer:** sponsor (Deposit or Mint)
- **msg.sender:** authorizer
- **Additional calldata:** session_config + 20 bytes

### Combined Verification Order

```
1. [Session Verification] -- Full session validation flow
   -> Failure -> reject (sponsor state unchanged)

2. [Sponsor Verification] -- Full sponsor pre-execution checks
   -> Failure -> reject (session state unchanged)

3. [Execution]
   -> msg.sender = authorizer
   -> gas cost = sponsor handles (Mint or Deposit)
   -> Normal EVM execution

4. [Post-Execution]
   -> Session state updates (nonce, limits)
   -> Sponsor state updates (Mint: mint+limit / Deposit: balance+limit)
```

## PachiSystemTx (0x50)

```
PachiSystemTx = 0x50 || rlp([
  chain_id,
  nonce,                        // system nonce (monotonically increasing)
  to,                           // target (Dealer contract for VRF, Oracle state for OracleUpdate)
  value,                        // always 0
  data,                         // encoded function call
  system_tx_type,               // u8: 0=OracleUpdate, 1=VRFfulfill
])
```

- **from:** System address (`0x0000000000000000000000000000000000000000`)
- **Gas:** Zero (OracleUpdate is protocol duty; VRF fulfill gas is prepaid at requestVRF)
- **Signature:** None (generated by block builder directly)
- **Position in block:** After all user transactions
- **Ordering:** VRF fulfill tx MUST appear after its corresponding requestVRF user tx

### System TX Subtypes

| system_tx_type | Name | Mandatory | Data |
|---|---|---|---|
| `0x00` | OracleUpdate | Every block | Encoded PriceSnapshot |
| `0x01` | VRFfulfill | Per VRF request | key, randomValue, proof, partials, partialOwners |

### Block Ordering Constraints

```
Block N:
  [user tx 1]
  [user tx 2: contains requestVRF(seed_a)]
  [user tx 3]
  [user tx 4: contains requestVRF(seed_b)]
  ---
  [system tx: VRFfulfill for seed_a]     // MUST be after user tx 2
  [system tx: VRFfulfill for seed_b]     // MUST be after user tx 4
  [system tx: OracleUpdate]              // Always last
```

## Gas Cost Summary

| Tx Type | Overhead Gas | Notes |
|---------|-------------|-------|
| SessionTx (0x04) | +15,000 | Hash + policy parse + limit checks |
| SponsoredTx (0x05, Deposit) | +20,000 | Registry + policy + balance + settlement |
| SponsoredTx (0x05, Mint) | +15,000 | Registry + policy (no balance logic) |
| SessionSponsoredTx (0x06) | +25,000 | Session + sponsor combined |
| PachiSystemTx (0x50) | 0 | Free (prepaid or protocol duty) |
